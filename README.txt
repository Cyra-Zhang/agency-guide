代理商操作指南网站

一、网站内容
1. 新签代理商注意事项：包含《新签代理商首次交付同步事项与展业规范》12页展示图、PDF版及可编辑PPTX原文件。
2. 代理商创建流程：操作长图 + 视频教程。
3. 服务商采购平台操作指南：操作长图 + 视频教程。
4. 靠谱人APP商户入网操作指南：操作长图 + 视频教程。

二、本地预览
1. 解压整个网站文件夹。
2. 双击打开 index.html，即可在浏览器中预览。
3. 请保留 index.html 与 assets 文件夹的相对位置，不要单独移动 index.html。

三、网站部署
可将整个文件夹中的所有内容上传到 Netlify、静态网站服务器或其他支持静态网页托管的平台。
网站入口文件为 index.html。

四、页面功能
- 左侧固定目录，点击可跳转到对应内容。
- 手机端提供目录菜单。
- 操作长图与PPT页面支持点击放大查看。
- 三个操作视频可直接播放，也可单独下载。
- 视频已转换为浏览器兼容性更好的 H.264 MP4 格式，保留完整时长。
